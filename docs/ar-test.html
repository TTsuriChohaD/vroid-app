このスマホの Chrome で AR（カメラの映像の上に 3D を置く）ができるかを試すページです。キャラクターは使いません。カメラの映像は画面に出すだけで、保存も送信もしません。

試し方

  1. 「AR を始める」を押す（カメラの許可を聞かれたら許可する）
  2. スマホをゆっくり動かして床を映す → 床が見つかると白い輪が出る
  3. 画面をタップ → その場所に、パープルと同じ背の高さ（1.4 m）の目印を置く
  4. まわりを歩いて、床に立って見えるか・影・動きのなめらかさ（画面上の FPS）を見る
  5. 「終わる」で戻ると、下に結果が出ます
