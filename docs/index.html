VRM ビューア

スマホの中の VroidApp フォルダを選ぶと、キャラクターを表示します。
ファイルはこの端末の中だけで読み込み、どこにも送りません。
一度選ぶと、次からは自動で表示します。

キャラクターと衣装

このページについて

  • 1 本指で回す、2 本指で寄る・引く・ずらす。2 回タップで最初の見え方に戻ります
  • 選んだファイルはこの端末の中で読むだけで、外には送りません
  • 選んだフォルダ（または VRM）は、この端末の Chrome の中に保存し、次に開いたときに自動で表示します。空きが少ないときなどに Chrome が消すことがあります。そのときはもう一度選んでください
  • セリフや衣装を足したときは、「フォルダ」でもう一度選び直すと入れ替わります
  • 表示に three.js と three-vrm（どちらも MIT ライセンス）を使っています
